## Ważne przed podłączeniem / Before connecting

Instrukcja dotyczy **NM-RF-HAT** i opisuje montaż z urządzeniem CYD. W tym repozytorium nie ma jeszcze zweryfikowanego schematu połączenia z **NM-CYD-C5**. Przed podłączeniem sprawdź rzeczywisty pinout, napięcia oraz dokumentację użytej płytki — nie zakładaj, że połączenia są identyczne.

The manual describes **NM-RF-HAT** and its assembly with a CYD device. This repository does not yet contain a verified wiring diagram for **NM-CYD-C5**. Before connecting anything, check the actual pinout, voltage levels, and board documentation; do not assume the connections are identical.
